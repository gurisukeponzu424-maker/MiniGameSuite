# 1. Requirements — 2本目のミニゲーム「当たりはどれ？」を作る

## 目的

2本目のミニゲーム「当たりはどれ？」を作り、タップ操作だけで遊べる
集中力系ゲームをゲーム一覧に追加する。

## やること

- `src/games/atari/` ディレクトリを作り、`MiniGame` を満たすゲームを実装する
  - id: `atari`（URL は `/games/atari`）
  - 画面に色・形がランダムな四角を複数並べる
  - 画面上部に「今回の当たり」（例：赤い四角）を表示する
  - 当たりをタップ → スコア +1、次の問題（新しい当たり・配置）に進む
  - 外れをタップ → なし
  - 制限時間20秒。0秒になったら操作不可にして結果（スコア）を表示する
  - 「もう一回」ボタンで最初から遊べる
  - 残り時間・当たり判定・スコア計算は純粋関数にしてテストを書く（「10秒れんだ」と同じ方針）
- `src/games/index.ts` に登録用の import を1行追加する
- 作者名は仮の名前（「なぞ味のちゃぼ」）で登録する。あとで本人のニックネームに1行変更できる

## 受け入れ条件

- [ ] `npm run test` / `npm run typecheck` / `npm run lint` / `npm run build` がすべてエラーなしで通る
- [ ] ローカル（`npm run dev`）で一覧から「当たりはどれ？」を選び、最後まで遊んでスコアが出る
- [ ] `/games/atari` の URL を直接開いても 404 にならない
- [ ] PC（クリック）・スマホ（タップ）のどちらでも最後まで遊べる
- [ ] ゲーム内・コード・コミットに本名などの個人情報が入っていない

## やらないこと（スコープ外）

- 記録・ランキングの保存、ログイン
- 効果音・画像などの素材（使う場合は別作業で `docs/credits.md` とあわせて行う）
- 難易度の段階分け・レベルアップ要素（必要なら `docs/backlog.md` へ）
- 公開（push・PR・マージ）作業そのもの（実装後、指示があれば別途行う）
